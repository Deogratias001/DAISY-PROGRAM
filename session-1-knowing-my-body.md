# Session 1 — Knowing My Body

**Duration:** 3 hours · **Group:** 25 girls · **Facilitator:** 1
**Materials:** 3D-printed reproductive anatomy and menstrual cycle models, adolescent guide books, flip chart, anonymous question box

> Partners align this outline with their own DAISY curriculum and guide books. Keep language age-appropriate and use the local language where it helps.

## Learning outcomes

By the end of the session, girls can:

1. Describe the main body changes during puberty.
2. Name the parts of the female reproductive system using the 3D model.
3. Explain the menstrual cycle and how to manage periods hygienically.
4. Know where to get trusted information and help.

## Session flow

| Time | Activity | Notes |
| --- | --- | --- |
| 0:00–0:20 | Welcome, ground rules, icebreaker | Agree on respect, confidentiality and the right to pass |
| 0:20–0:30 | Quick knowledge check (pre) | Anonymous, no names |
| 0:30–1:00 | Puberty and body changes | Normalise differences between girls |
| 1:00–1:45 | Reproductive anatomy with 3D models | Girls handle the models in small groups |
| 1:45–2:00 | Break and refreshments | |
| 2:00–2:40 | Menstrual cycle and menstrual hygiene | Use the cycle model; address myths |
| 2:40–2:55 | Anonymous question box | Answer every question respectfully |
| 2:55–3:00 | Wrap-up and preview of Session 2 | |

## Facilitator notes

- Never single out or pressure a girl to speak.
- If a girl discloses abuse or risk, follow `../safeguarding-and-media.md` the same day.
- Record common questions (without names) in the sub-session report.
