# Reporting

Every sub-session is reported within 24 hours using the templates in this folder.

| Report | Template | Who | When | Sent to |
| --- | --- | --- | --- | --- |
| Sub-session report | `sub-session-report.md` | Each facilitator | Within 24 hours | Partner lead, copy to Eco-Prints |
| Attendance register | `attendance-register.csv` | Each facilitator | With the sub-session report | Partner lead (secure drive only) |
| Daily summary | `daily-summary.md` | Partner lead | End of each session day | Eco-Prints |
| Weekly report | `weekly-report.md` | Partner lead | End of each week | Eco-Prints |
| Consolidated report | — | Eco-Prints Generation | Within 5 working days of the last session | UNFPA / YSW |

**File naming:** `YYYY-MM-DD_<ward>_S<1|2>_<AM|PM>.md` — for example `2026-11-10_kipevu_S1_AM.md`.

Completed registers contain personal data and stay in the secure drive. Only anonymised reports may be committed here.
