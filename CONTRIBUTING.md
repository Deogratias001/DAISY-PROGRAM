# Contributing

1. Create a branch for your change (`report/2026-11-10-kipevu`, `docs/session-2-update`).
2. Use the templates in `reporting/` and the file naming rule in `reporting/README.md`.
3. Check that **no personal data** is included (see `data/README.md`).
4. Open a pull request; an Eco-Prints coordinator reviews and merges.

Not comfortable with Git? Send your completed report to the Eco-Prints coordinator, who will add it.
